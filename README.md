# راد مدرن — وب‌سایت HTML

وب‌سایت استاتیک فارسی با HTML، CSS و JavaScript ساده.

## اجرای محلی

از ریشه پروژه یک وب‌سرور محلی اجرا کنید:

```powershell
python -m http.server 5500
```

سپس آدرس `http://localhost:5500` را باز کنید.

## ساختار اصلی

- `index.html`: صفحه اصلی
- `about.html`: معرفی و رویکرد
- `contact.html`: فرم آماده‌سازی ایمیل
- `nemonekar.html`: نمونه‌های مفهومی
- `maghalat.html`: فهرست مقالات
- `article.html`: قالب نمایش مقاله
- `articles.js`: داده‌های مقالات
- `site.css` و `home.css`: استایل‌ها
- `image/`: تصاویر مورد استفاده

## نکات مهم انتشار

- فرم تماس در نسخه فعلی بک‌اند ندارد؛ اطلاعات را در برنامه ایمیل کاربر آماده می‌کند و کاربر باید ارسال نهایی را تأیید کند.
- نمونه‌های صفحه نمونه‌کار، مفهومی هستند و نباید به‌عنوان پروژه تحویل‌شده به مشتری معرفی شوند.
- پیش از انتشار نهایی، نشانی ایمیل، اطلاعات تماس، مجوز تصاویر و ادعاهای تجاری را با اطلاعات واقعی کسب‌وکار تطبیق دهید.
- سایت را پس از هر تغییر در موبایل و دسکتاپ بررسی کنید.
